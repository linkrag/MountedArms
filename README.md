# Mounted Arms

RimWorld 1.6 mod: turrets based on modern mounted weapons (M240, M2, Mk19, M134, Mk44, TOW, rocket pod, CIWS, M252 mortar, guided rocket battery), with a Combat Extended compatibility layer.

- `1.6/Defs` vanilla defs, `1.6/CE` Combat Extended patches (loaded only with CE), `Source` C# (Harmony), `Docs/RULES.md` project rules and calibration, `Docs/TEMPLATE_NOVA_TORRETA.md` checklist for new turrets.
- Package id: `linkrag.mountedarms`. Requires Harmony.
