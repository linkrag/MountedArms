# Changelog - Mounted Arms

Versioning: SemVer. 1.0.0 = first Steam Workshop publication (2026-11-07). MINOR = new feature, PATCH = fixes/tweaks. Before each Workshop upload, bump `<modVersion>` in `About/About.xml`, this file and the Changelog section of `Docs/WORKSHOP_DESCRIPTION.txt` together (player-facing text, English).

## 1.0.1 (2026-11-13)
- Combat Extended: the Stinger missile recipe's "Until X" now steps by 4, one craft's output, instead of 20.

## 1.0.0 (2026-11-07)
- 17 real-world turrets, from a hand-cranked Gatling gun to the Phalanx, Goalkeeper and Iron Beam laser.
- Own research tab and a dedicated Military tab in the Architect menu for all turrets.
- Barrels overheat and need cooling; without Combat Extended, turrets traverse gradually and sustained fire spreads more.
- Rockets and missiles launch with backblast, motor ignition and muzzle effects; damaged turrets may explode.
- Optional Combat Extended support: real CE ammunition, ranges and aiming, plus an Unload button to swap ammo.
- With CE's CIWS option on, air-defense guns intercept shells and missiles, and some also shoot down drop pods.
- Supports RimWorld 1.6 and 1.7; partial Portuguese (Brazil) translation of interface messages.
